# 访客端功能设计

访客通过首页发现最近更新，通过博客页查找文章或专栏，再进入对应的阅读页。顶部导航提供首页、博客、实验室和关于四个入口；访问 `/` 会转到 `/home`。

| 页面 | 访客操作与结果 |
|---|---|
| `/home` | 「最新文章」混排普通博客与单个章节，按各自更新时间取前 10 条。点击章节直接打开该章。下方显示最近 5 条个人动态，侧栏展示资料、公告和站点统计。 |
| `/blog` | 在文章和专栏之间切换。文章每页 10 篇，页码写入 URL；专栏视图展示专栏卡片。点击搜索框、侧栏标签或使用 Ctrl/Cmd + K 打开搜索，按标题或标签查询两类结果。目前发送给后端的标签过滤值为第一个已选标签。 |
| `/blog/[id]` | 查看标题、日期、标签与 Markdown 正文，利用文内目录定位标题。文章下方通过 Giscus 加载与当前路径关联的评论。 |
| `/column/[slug]` | 查看专栏介绍和按发布目录排列的章节，选择章节开始阅读。 |
| `/column/[slug]/[chapter]` | 阅读当前章，通过专栏目录或上一章、下一章链接切换；首尾章节只提供存在的方向。 |
| `/lab`、`/about` | 实验室展示项目和服务器状态；关于页展示个人经历、技术栈、友链和赞助信息。项目及个人资料由前端维护，服务器状态来自 API。 |

## 时间、语言与空态

首页采用博客的 `updatedAt` 和各章独立的 `updatedAt`。只手动更新 B 时，B 可以重新排到前面，未改动的 A 保留原来的排序时间。文章详情继续展示文章日期。侧栏「站点统计」分别显示已发布文章数和专栏数；「最近更新」取两类内容最近一次更新，换算为距今天数。更新单章后，所属专栏的新时间也参与统计；没有可用时间时显示短横线。[首页](../../src/app/home/page.tsx) · [排序](../../src/lib/feed.ts) · [统计卡片](../../src/components/home/SiteStats.tsx)

界面支持英文和简体中文，初始语言由站点配置决定；切换语言会更新界面文案和双语动态，文章与章节展示作者提交的原文。首页两类内容独立取数，单个专栏详情加载失败会跳过该栏；全部条目为空时显示骨架卡片。博客或章节详情无法取得数据时，页面调用 Next.js 的 `notFound()`。[站点配置](../../src/lib/config.ts) · [视觉设计](visual.md) · [实现架构](../implement/architecture.md)
